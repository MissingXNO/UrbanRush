# Urban Rush

> **2D endless runner developed with Godot 3.3.0**

**Urban Rush** is a 2D endless runner where the player controls a roller skater who must avoid obstacles, collect coins and achieve the highest possible score.

The project was developed as a personal/academic project using **GDScript** and **Godot Engine 3.3.0**, focusing on gameplay programming, 2D physics, animation, UI, audio and local data persistence.

---

## Gameplay

<img width="480" alt="Urban Rush gameplay" src="https://github.com/user-attachments/assets/55bc7636-750f-47e7-bb07-d94ca77b4ae7" />

The player remains near the left side of the screen while obstacles and collectibles move toward them.

### Core mechanics

* **Jump** over obstacles.
* **Slide** underneath obstacles.
* **Hold jump** to control jump height.
* **Collect coins** for additional points.
* Avoid different obstacle configurations.
* Survive as long as possible to increase the score.
* The game ends when the player collides with an obstacle.

## <img width="32" height="32" alt="options button" src="https://github.com/user-attachments/assets/ba5e003a-21b6-4498-99e7-d5170754b09e" /> Features

* Randomized obstacle and coin spawning.
* Multiple obstacle and coin configurations.
* Variable-height jumping.
* Gravity-based player movement.
* Dynamic camera zoom during vertical movement.
* Animated player states: running, jumping, falling and sliding.
* Main menu, options menu, HUD and pause menu.
* Music and sound-effect controls.
* Touchscreen controls for mobile gameplay.
* Persistent local high score.
